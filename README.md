# Merge Sort in C

A simple implementation of **Merge Sort** using recursion and the divide-and-conquer approach.

### Concepts Used

* Arrays
* Functions
* Recursion
* Divide and Conquer

### Complexity

* **Best:** O(n log n)
* **Average:** O(n log n)
* **Worst:** O(n log n)
* **Space:** O(n)

### Output

```text
Sorted Array:
0 1 2 3 5 6 7 8 9
```
